# Firefly prompts — Bible TCG (57 cards)

## How to use (Adobe Firefly)

1. Go to **firefly.adobe.com** → **Text to Image** (sign in with your Adobe ID).
2. Settings on the right panel:
   - **Aspect ratio:** Portrait (3:4). *(Card art is cropped to fill, so 3:4 is close enough — no exact 5:7 needed.)*
   - **Content type:** Art (not Photo).
   - **Model:** the latest Firefly Image model (default).
3. Paste a prompt below, generate (you get 4 variations), pick the best, **Download**.
4. **Rename the file to exactly the card id**, e.g. `h_samson.jpg` (Firefly exports JPG; that's fine).
5. Put all renamed images in one folder, then run the importer from the project folder:
   `python3 import-art.py ~/Downloads/bible-art`
6. Rebuild the app — the paintings replace the placeholders automatically.

**Consistency (do this!):** generate one card you love, then use Firefly's **Style reference**
(upload that image under "Styles → Reference image") and reuse it for all 57 so the whole set
shares one cohesive look. You can also save/apply a **Style effect** for the same reason.

**Credits:** Firefly generations use your Creative Cloud monthly generative credits.
